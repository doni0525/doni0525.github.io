# 见己 · PWA（含 AI 智能分析）

个人思考与表达成长系统。手机优先，可添加到主屏幕当 APP 用，支持离线。

## 本次更新：AI 全流程一条龙

新增「知识理解与创作」工作流，五步走完：
1. **素材** — 贴一段文章、观点或笔记
2. **拆解** — AI 提炼核心概念、论证逻辑、隐藏前提、可质疑点
3. **追问** — 苏格拉底式追问，帮你把知识内化成自己的（可多轮）
4. **创作** — 选知识卡/短文/口述稿/观点陈述，AI 写初稿，你来改
5. **沉淀** — AI 点评润色，一键存入观点库

同时在三处接入了 AI 深度分析（与本地规则并存，按需点击）：
- 表达练习 → AI 深度点评（五维）
- 每日记录 → AI 洞察这条记录
- 每周成长 → AI 深度分析本周

## 首次使用 AI（一次性配置）

1. 到 [DeepSeek 控制台](https://platform.deepseek.com/api_keys) 注册并创建 API Key（新用户有免费额度）。
2. 在 App 里进入 **我的 → AI 智能分析**：
   - 打开「启用 AI 能力」
   - 粘贴 API Key
   - 接口地址和模型保持默认（`https://api.deepseek.com/v1` / `deepseek-chat`）即可
   - 点「保存配置」，再点「测试连接」确认成功
3. 回到「练习 → 知识理解与创作」即可开始。

**关于密钥与费用**
- 密钥只保存在本机浏览器，**不写入导出的备份文件**，也不会发给除 AI 服务商以外的任何一方。
- AI 调用按服务商标准计费（DeepSeek 很便宜，新用户有免费额度）。每次都是你主动点击才发送。
- 默认反馈、周报等本地规则功能不联网、不产生费用。
